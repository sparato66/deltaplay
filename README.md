# Дельта Гейм

Україномовний календар великих майбутніх ігор на GitHub Pages. У каталозі лише відібрані проєкти великих франшиз, AAA-релізи та значущі ремастери з окремими досьє, офіційними трейлерами, матеріалами, платформами й посиланнями.

## Дані й оновлення

Каталог формується зі статичного редакційного файлу `editorial-games.json`. Скрипт `scripts/build-curated-catalog.mjs` перевіряє обов’язкові поля та створює `games.json`; мережевий збір і магазинні каталоги не використовуються. Рік і дата показуються лише тоді, коли їх підтвердив видавець, студія або платформа. У роках без достатньої кількості перевірених масштабних релізів сайт показує порожню добірку.

Оновлення публікуються після змін у `main` або вручну через GitHub Actions. Перелік 20 редакційних орієнтирів доступний на головній сторінці, а кожне досьє містить власні першоджерела та джерело звірки.

## Запуск локально

```sh
node scripts/build-curated-catalog.mjs
python3 -m http.server 8000
```

Потім відкрийте `http://localhost:8000`.
