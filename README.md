# DeltaPlay

Україномовний сайт про відеоігри та творчість: каталог ігор 2004–2025, окремі сторінки кожної гри, пошук, фільтри, обране, збереження улюблених ігор, редакційні матеріали та AI Lab у демо-режимі.

## Запуск

Відкрий `index.html` у браузері або запусти будь-який простий статичний сервер з цієї папки (наприклад, `python3 -m http.server 8000`). Залежностей і збирання немає.

## Структура

- `index.html`, `styles.css`, `app.js` — сайт і клієнтська логіка.
- `games.js` — каталог і редакційні записи.
- `game.html` — автономний екран сторінки гри, адресований через `?id=slug`.
- `assets/` — локальні авторські SVG-ресурси.
- `scripts/fetch-steam-media.mjs` — формує маніфест скриншотів зі Steam під час GitHub Actions деплою.
- `.github/workflows/pages.yml` — автоматична публікація на GitHub Pages після push у `main` (після одноразового ввімкнення Pages у налаштуваннях репозиторію).

## AI Lab

Вбудована лабораторія працює в локальному демо-режимі: формує структурований стартовий план у браузері й не надсилає введений текст у мережу. Для справжнього мовного ШІ потрібні серверний API-проксі, ключ постачальника та його окреме налаштування. Не додавай API-ключ у клієнтський код чи публічний репозиторій.

## Контент і зображення

Опис ігор — короткі редакційні анотації, це не вичерпна база всіх релізів. Арт і картки завантажуються з публічного CDN Steam; права на ігрові зображення належать відповідним правовласникам. Сайт показує джерело на сторінці гри. Для показу постерів і скриншотів потрібен інтернет. GitHub Actions оновлює список ілюстрацій під час деплою; якщо Steam тимчасово недоступний, сторінка гри показує арт і обкладинку як резервний варіант.

## Публікація

Створи публічний репозиторій, запуш `main` і ввімкни GitHub Pages з GitHub Actions. Кроки: [документація GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
