# Дельта Гейм

Проста україномовна стрічка майбутніх відеоігор з окремою сторінкою кожного релізу.

## Як оновлюється

GitHub Actions автоматично збирає список зі сторінки Steam «Майбутні релізи», перевіряє кожну гру через Steam Store appdetails та оновлює описи, дату, розробників, видавців, платформи, трейлери, зображення й посилання. Стрічка перебудовується кожні 12 годин і після змін у коді. Ручний запуск доступний у вкладці Actions.

Автоматичний збір не використовує окремого мовного ШІ: Steam надає структуровані дані про релізи без ключа, а підключення зовнішньої генеративної моделі потребувало б окремого сервісу та секретного ключа. Код не називає звичайний збір даних «ШІ».

## Запуск локально

Відкрий `index.html` через локальний HTTP-сервер. Для оновлення даних виконай `node scripts/fetch-upcoming.mjs` (потрібен доступ до інтернету).
